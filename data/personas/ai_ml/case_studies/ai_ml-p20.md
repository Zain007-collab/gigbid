# Visual defect detection for a healthcare line

**Client:** a healthcare organisation (anonymised). **Year:** 2023.

## Problem
The client needed help with visual defect detection for a healthcare line. Their existing process was manual and slow.

## What I did
I designed and delivered the solution using PyTorch. Supporting pieces included containerised deployment; async Python backend.
I wrote documentation and handed over with a recorded walkthrough.

## Result
We reached 61% precision at 54% recall on held-out images.
