# Visual defect detection for a e-commerce line

**Client:** a e-commerce organisation (anonymised). **Year:** 2021.

## Problem
The client needed help with visual defect detection for a e-commerce line. Their existing process was manual and slow.

## What I did
I designed and delivered the solution using PyTorch. Supporting pieces included reproducible container setup; async Python backend.
I wrote documentation and handed over with a recorded walkthrough.

## Result
We reached 44% precision at 55% recall on held-out images.
