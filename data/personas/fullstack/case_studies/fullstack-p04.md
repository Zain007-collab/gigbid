# Public GraphQL API for a fintech marketplace

**Client:** a fintech organisation (anonymised). **Year:** 2024.

## Problem
The client needed help with public graphql api for a fintech marketplace. Their existing process was manual and slow.

## What I did
I designed and delivered the solution using GraphQL, Node.js. Supporting pieces included relational database; containerised deployment.
I wrote documentation and handed over with a recorded walkthrough.

## Result
We served 9 million requests a month at p95 under 200 ms.
