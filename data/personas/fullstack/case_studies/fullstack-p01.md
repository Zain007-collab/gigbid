# Customer dashboard for a e-commerce SaaS

**Client:** a e-commerce organisation (anonymised). **Year:** 2023.

## Problem
The client needed help with customer dashboard for a e-commerce saas. Their existing process was manual and slow.

## What I did
I designed and delivered the solution using Next.js, TypeScript. Supporting pieces included type-safe ORM; SQL database design; utility-first styling.
I wrote documentation and handed over with a recorded walkthrough.

## Result
We cut page load from 6s to 2s.
