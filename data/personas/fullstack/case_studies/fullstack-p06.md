# Test automation for a SaaS web app

**Client:** a SaaS organisation (anonymised). **Year:** 2025.

## Problem
The client needed help with test automation for a saas web app. Their existing process was manual and slow.

## What I did
I designed and delivered the solution using Playwright, TypeScript. Supporting pieces included reproducible container setup; cloud deployment on Amazon.
I wrote documentation and handed over with a recorded walkthrough.

## Result
We raised release frequency from 2 to 5 per month.
