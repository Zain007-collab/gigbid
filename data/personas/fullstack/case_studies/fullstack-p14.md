# Test automation for a healthcare web app

**Client:** a healthcare organisation (anonymised). **Year:** 2025.

## Problem
The client needed help with test automation for a healthcare web app. Their existing process was manual and slow.

## What I did
I designed and delivered the solution using Playwright, TypeScript. Supporting pieces included containerised deployment; S3 and Lambda setup.
I wrote documentation and handed over with a recorded walkthrough.

## Result
We raised release frequency from 1 to 7 per month.
